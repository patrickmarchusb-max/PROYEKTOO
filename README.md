# PROYEKTO

**Mapping Needs. Simulating Solutions.**

PROYEKTO is a GIS-based community development decision-support prototype. It demonstrates service-gap mapping, hypothetical facility placement, before/after accessibility simulation, candidate-site comparison, and a secondary livelihood/skills module.

> Prototype only: all community values and simulation results are mock data and are not official government findings.

## Run locally

1. Install Node.js.
2. Clone this repository.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown by Vite.

## Core demo workflow

Service Gap Map → Select Community → Understand Why → Project Simulator → Place Facility → Before/After → Compare Sites.

The Service Gap Index currently uses demonstration weights only. Real deployment requires validated data, criteria, weights, stakeholder consultation, and feasibility assessment.
